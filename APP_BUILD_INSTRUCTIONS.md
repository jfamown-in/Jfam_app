# JFAM Customer App Build Instructions

This project is now wrapped with Capacitor for Android.

## Regular Web/App Changes

Edit these main source files:

- `index.html`
- `dairy-app.css`
- `script.js`
- `Supabase.js`
- `images/`

After every change, run:

```powershell
npm run build
npx cap sync android
```

This copies the latest web app into the Android app.

## Open Android App

```powershell
npx cap open android
```

Android Studio will open. From there, run the app on an emulator or connected phone.

## Build APK From Android Studio

In Android Studio:

1. Open the `android` project when prompted.
2. Wait for Gradle sync to finish.
3. Go to `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
4. Android Studio will show the APK location after the build completes.

## Important

Do not edit files inside `www/` manually. It is generated by `npm run build`.

For app id/package name, the current Android id is:

```text
com.jfam.customer
```
